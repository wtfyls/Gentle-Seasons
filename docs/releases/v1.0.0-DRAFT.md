# 🌿 Gentle Seasons v1.0.0 — Draft release notes

> **DRAFT — do not publish until the listed features have been implemented and tested.** The current source implements time-cycle multipliers and a rain-growth bonus. Gentle Weather and Campfire Comfort below are planned, not included in the current build.

Initial release target: **Minecraft 1.20.1 · Forge 47.x · Java 17**

## ✨ Features

- 🌧️ **Rain-assisted crop growth:** exposed age-based crops have a configurable 50% chance of gaining an extra growth stage after a compatible crop-growth event succeeds during rain.
- ☀️ **Longer daytime:** default daylight multiplier of `2.0`, targeting a 20-minute day period at normal 20 TPS.
- 🌙 **Shorter nights:** default nighttime multiplier of `0.5`, targeting a 5-minute night period at normal 20 TPS.
- 🌦️ **Gentle Weather:** planned — longer clear periods and rainstorms bounded to 5–10 minutes.
- 🔥 **Campfire Comfort:** planned — intended to remove Mining Fatigue and Weakness and grant Regeneration I near a lit campfire.

## 📦 Compatibility and requirements

# Gentle Seasons v1.0.0 — Draft

**Target:** Minecraft 1.20.1 · Forge 47.x · Java 17

## Features

- Longer days and shorter nights.
- Configurable rain-assisted crop growth.

Weather changes and campfire effects are not in this build yet.

Test the jar in-game, confirm the build passes, and attach the tested file to the release. Do not publish this draft until the feature list matches the final jar.
